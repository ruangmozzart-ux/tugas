Panduan Integrasi Google Sheets (Aman di Akun Guru)

Agar data jawaban siswa tersimpan secara privat dan hanya masuk ke spreadsheet di akun email Anda saja, ikuti langkah ini menggunakan akun Google pribadi Anda:

  1. Buka Google Drive (pastikan sudah login dengan email Anda) dan buat Google Spreadsheet baru.
  2. Buat header kolom di Baris 1: Timestamp, ID, Nama, Kelas, Absen, Kelompok, Masalah, Penyebab, Dampak, Decomposition, Pattern, Abstraction, Algorithm, PM, SA, Designer, Communicator, Solusi, Target, Manfaat, Alur, WireframeInfo, Refleksi, Kesimpulan, SkorMesin, NilaiAkhir, Status.
  3. Klik Ekstensi > Apps Script.
  4. Hapus kode yang ada, ganti dengan kode di bawah ini.
  5. Klik Terapkan (Deploy) > Penerapan Baru. Pilih jenis Aplikasi Web. Akses: "Siapa saja".
  6. Copy URL Web App, dan masukkan ke baris kode JavaScript const APPS_SCRIPT_WEB_APP_URL = "https://script.google.com/macros/s/AKfycbyiHadWmudOC85KC5HGYd5mCWEGdnkza9Iwu3v7eiLZqrzEjFFi6Vhbg7pTa_QGqLCrwg/exec"; pada file ini.
function doPost(e) {
  try {
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    const data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      new Date(), data.id, data.nama, data.kelas, data.absen, data.kelompok,
      data.masalah, data.penyebab, data.akibat, data.decomposition, data.pattern, 
      data.abstraction, data.algorithm, data.pm, data.sa, data.designer, 
      data.communicator, data.solusi_nama, data.solusi_target, data.solusi_manfaat,
      data.alur, data.wireframe_desc, data.refleksi, data.kesimpulan, 
      data.skor, data.nilai_akhir, "SUDAH DIKIRIM"
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({"status": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
